# Valthoris Privacy Framework

## Purpose

This document defines the privacy framework governing the Valthoris platform.

It establishes the principles, controls and governance mechanisms used to protect personal data and ensure compliance with European privacy legislation.

---

# Privacy Principles

The platform follows:

- Privacy by Design
- Privacy by Default
- Data Minimisation
- Purpose Limitation
- Storage Limitation
- Accuracy
- Integrity and Confidentiality
- Accountability

---

# Applicable Legislation

Valthoris is developed in accordance with:

- General Data Protection Regulation (GDPR / RGPD)
- NIS2 Directive
- Cyber Resilience Act (CRA)
- EU AI Act
- ENISA Recommendations

---

# Personal Data Categories

The platform may process:

- User identification data
- Authentication information
- Fraud reports
- Device metadata
- Network metadata
- AI analysis results
- Threat intelligence metadata

Sensitive personal data shall only be processed where legally justified.

---

# Data Collection

Only the minimum amount of information necessary for fraud prevention shall be collected.

No unnecessary personal information shall be stored.

---

# Data Storage

All stored data must be protected through:

- Encryption at rest
- Encryption in transit
- Row Level Security (RLS)
- Access control
- Secure backups

---

# User Rights

Users retain all rights established under GDPR, including:

- Right of access
- Right of rectification
- Right of erasure
- Right to restriction
- Right to portability
- Right to object

---

# Artificial Intelligence & Privacy

AI systems shall:

- respect user privacy;
- avoid unnecessary profiling;
- provide explainable decisions where applicable;
- minimise personal data usage.

---

# International Data Transfers

International transfers shall only occur under legally recognised safeguards.

---

# Data Retention

Personal data shall be retained only for the minimum period necessary to fulfil legal and operational purposes.

---

# Governance

Privacy governance is coordinated with:

- Compliance Framework
- Security Architecture
- Data Governance
- AI Governance

---

# Review

This document shall be reviewed whenever applicable legislation changes or major platform architecture changes occur.
