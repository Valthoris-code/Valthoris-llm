# Valthoris Data Classification Policy

## Purpose

This document defines the official data classification policy for the Valthoris platform.

It establishes how information is classified, protected, handled and retained throughout its lifecycle.

---

# Objectives

The objectives of this policy are to:

- protect sensitive information;
- support GDPR compliance;
- reduce information leakage;
- ensure appropriate security controls;
- support risk-based security decisions.

---

# Data Classification Levels

## 1. Public

Information approved for public disclosure.

Examples:

- Marketing materials
- Public documentation
- Public APIs
- Public threat intelligence

---

## 2. Internal

Information intended only for internal use.

Examples:

- Internal documentation
- Development notes
- Operational procedures
- Internal dashboards

---

## 3. Confidential

Information that could negatively impact Valthoris if disclosed.

Examples:

- Internal reports
- Investigation data
- Threat intelligence correlations
- Security logs
- AI model configurations

---

## 4. Restricted

Highly sensitive information requiring maximum protection.

Examples:

- Cryptographic secrets
- Private keys
- Authentication credentials
- Incident response evidence
- Security infrastructure
- Production configuration

---

# Handling Requirements

Each classification level requires:

- appropriate access control;
- encryption where applicable;
- secure storage;
- secure transmission;
- controlled sharing.

---

# Access Control

Access shall follow:

- Least Privilege
- Need-to-Know
- Role-Based Access Control (RBAC)
- Zero Trust principles

---

# Storage Requirements

Data shall be protected using:

- Encryption at rest
- Encryption in transit
- Secure backups
- Row Level Security (RLS)
- Audit logging

---

# Retention

Information shall only be retained for the minimum legally and operationally required period.

---

# Disposal

When data reaches end-of-life it shall be securely destroyed using approved deletion procedures.

---

# Compliance

This policy supports compliance with:

- GDPR
- NIS2
- Cyber Resilience Act
- EU AI Act
- ENISA recommendations
- ISO/IEC 27001
- ISO/IEC 27701

---

# Governance

This policy is part of the Valthoris Governance Framework and shall be reviewed periodically.
